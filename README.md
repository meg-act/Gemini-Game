# JR常磐線 運転シミュレーター（日暮里〜北千住）

Three.js（物理ベース大気散乱・リアルタイムIBL環境反射・PBRマテリアル・HDR Bloomポストプロセス）と Web Audio API プロシージャル音響合成による、一人称視点のフォトリアル志向・電車運転シミュレーターです。

## 主な特徴

### 1. 実車準拠 E531系 2画面グラスコックピット運転台
- ダークチャコール計器コンソール＋ライトグレーデスク（手前左右分割ブラックソフトパッド肘当て・中央切り欠き付）のツートン構成
- **左手操作ワンハンドル主幹制御器（マスコン）**: 左デスク埋め込み式ノッチガイドプレート（前後切換丸玉レバーサー付）から伸びる銀色金属ステー＋黒L字グリップ＋銀ロック解除ボタンが、ノッチ操作に応じてスリット内をスライド＆スイング
- **固定式 右手用握り棒（勾配起動スイッチ付）**: 中央デスクに備わる右支柱・左張り出しの黒い持ち手（緑キャップ付）をマスコンと明確に分離して忠実再現
- **左液晶（計器表示器）**: 160 km/h アーク速度計、デジタル速度、縦バー式 BC/MR 圧力計、架線電源 `[DC]` ＆電圧・電流計、ATS-P 表示
- **中央コラム＆右液晶（TIMS）**: 赤色「緊急」ボタン、アンバー電球フード付きセイコー鉄道懐中時計、TIMS採時駅時刻表・15両編成状態図、ICカードスロット、デジタル列車無線パネル、車内・指令電話受話器、左上小型監視モニタ＆蛇腹ダクト

### 2. 実物配線＆現代のJR駅構造物（実寸 5.2 km）
- **日暮里駅 (JJ 02 / 0.0 km) 14線メガコリドー**:
  - 東側：京成本線 2層高架駅・プレートガーダー跨線橋、日暮里・舎人ライナー高架軌道、ステーションガーデンタワー
  - 常磐快速線：3・4番線島式ホーム（下り4番線＝右側ホーム）
  - 東北本線・高崎線・尾久回送線（欠番5〜8番線相当）：**実物通りの4線**（渡り線分岐器付）
  - **東北・上越・北陸新幹線（標準軌2線）**: 下御隠殿橋北側の **第1上野トンネル日暮里抗口** から地上へ姿を現し、コンクリートのU字擁壁急勾配アプローチを駆け上がって白い防音壁付き新幹線高架橋へ至る立体交差を完全再現
  - 京浜東北線・山手線（9〜12番線 方向別複々線）：島式ホーム2面4線、エキュート日暮里橋上駅舎、トレインミュージアム「下御隠殿橋」、西端の谷中霊園樹林崖線
- **三河島駅 (JJ 03 / 1.2 km)**: 常磐線名物の急激な右大カーブを抜けた島式1・2番線高架ホーム、アトラスブランズタワー、田端貨物支線合流高架
- **南千住駅 (JJ 04 / 3.4 km)**: 東京ガス千住整圧所の球形ガスタンク2基、JR貨物・隅田川駅（EH500電気機関車＋コキ貨物編成・コンテナヤード）、汐入タワーマンション群、南東遠景にそびえる **東京スカイツリー（634m）**
- **隅田川橋梁**: 2連曲弦ワーレントラス橋、夕焼けを反射する隅田川水面、上流の千住大橋・下流のつくばエクスプレス橋梁
- **北千住駅 (JJ 05 / 5.2 km)**: 都内JR唯一の **2面3線配線**（左側1番線単式ホーム・中央2番線中線待避線と停車中のE531系・右側2/3番線島式ホーム・3番線上り本線）、東側の東京メトロ日比谷線／東武スカイツリーライン地上3階高架駅、西口ルミネ・北千住マルイ
- **高密度駅設備**: ATOS 2段フルカラーLED発車標、黄色い出口・乗換案内ボード、運転士用4画面ITVホーム監視モニター、ガラス張り空調待合室、階段・エスカレーター囲い室、acure自動販売機、`[15]` 停止位置目標

### 3. 超高精細 対向・並走車両ラインナップ
- **E531系0番台（常磐線 交直流10両編成）**: 丸屋根ベジェ断面＋2048px PBRステンレス車体、**中央ホワイト逆台形＋左右45°斜めコバルトブルー前面**、上部粒目HIDライト、大型V字強化スカート＆柴田式密着連結器・電気連結器、AU726クーラー、フランジ車輪付ボルスタレス台車・床下機器、**4・5号車 2階建てグリーン車（サロE531：中央極太ブルー帯・四つ葉マーク付）**
- **E231系0番台（常磐快速 10両編成）**: パールホワイトFRP額縁マスク、エメラルドグリーン＋ウグイス2色帯の**さらに下に独立配置された横長ブラックライトケース帯**、緑塗装の乗務員扉、下部角型電球色ヘッドライト
- **日暮里並走他路線車両（実車の番線・進行方向に完全一致）**:
  - **東北新幹線 E5系「はやぶさ」**: 常盤グリーン＋はやてピンク＋飛雲ホワイト、15m超ロングノーズ造形（下りトンネル抗口から高架橋へ急勾配クライム）
  - **東北本線（宇都宮・高崎線 / 上野東京ライン）**: E231系1000番台 湘南色2色帯（2階建てグリーン車連結、上下線走行）
  - **山手線 E235系0番台**: 黒フェイス＋ウグイス色ドットグラデーション額縁＋扉縦ウグイス帯（10番線外回り・11番線内回り）
  - **京浜東北線 E233系1000番台**: ブラックフェイス＋スカイブルー帯（9番線南行・12番線北行）

## 操作方法
| キー | 操作 |
| :--- | :--- |
| `S` / `↓` / `Z` | マスコンを手前に引く（制動解除 → 力行 `P1`〜`P5`） |
| `W` / `↑` / `Q` / `.` | マスコンを奥へ押す（力行解除 → 常用制動 `B1`〜`B8` → `EB`） |
| `Space` / `N` | 惰行（`N`）へ戻す |
| `Backspace` / `E` / `/` | 非常ブレーキ（`EB`）投入 |
| `H` / `Enter` | 警笛（電笛・空笛） |
| `D` | 駅停車中の客室扉開閉（戸閉保安連動） |
| `V` | 視点切替（3D運転席視点 ↔ 前面展望フルビュー） |
| `M` | 音声ミュート切替 |
| `Tab` | アシストHUDの表示／非表示切替 |
| `1` / `2` / `3` | 時間帯切替（茜色マジックアワー / 黄金色の夕暮れ / 群青の薄暮） |
| マウスドラッグ / ダブルクリック | 運転席からの首振り（フリールック） / 正面リセット |
