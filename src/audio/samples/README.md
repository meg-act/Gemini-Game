# 実録サンプリング音源配置フォルダ (`src/audio/samples/`)

このフォルダに以下のファイル名（拡張子は `.wav` / `.mp3` / `.ogg` / `.m4a` いずれでも自動認識）を配置するか、スタート画面の **「音源ファイルを選択」**（またはウィンドウへのドラッグ＆ドロップ）で読み込むと、内蔵シンセから実音再生へ自動で切り替わります。

## 1. 車両効果音（3〜4ファイル）
| ファイル名 (拡張子自由) | 用途・再生タイミング |
| :--- | :--- |
| `horn` | 警笛（`H` / `Enter` キー — 空笛タイフォンまたは電笛＋空笛） |
| `horn_elec` *(任意)* | 電笛単体（`Shift + H` で鳴らし分けたい場合のみ。無ければ `horn` を使用） |
| `door_open` | 開扉チャイム＋ドア開音（停車中 `D` キー開扉時） |
| `door_close` | 閉扉チャイム（3連）＋ドア閉・戸閉ロック音（停車中 `D` キー閉扉時） |
